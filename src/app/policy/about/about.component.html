About GymTracker

GymTracker is a personal workout tracking application designed to help users organize workouts, build routines, and monitor their fitness progress over time.

Features

GymTracker provides the following core features:

  • Workout logging
  • Custom workout routines
  • Workout history and progress tracking
  • Secure user accounts

Project Goal

The goal of GymTracker is to provide a simple, fast, and distraction-free experience for tracking workouts. The application focuses on making it easy to record your training sessions and review your fitness journey without unnecessary complexity.

About This Project

GymTracker is an independent personal project developed and maintained by a single developer. It was created as both a practical fitness tool and an opportunity to build and improve full-stack development skills.

Technology Stack

GymTracker is built using modern web technologies:

  • Angular
  • Dotnet
  • PostgreSQL
  • Neon Database
  • Render
  • Vercel
